# Writing examples

These are the current managed self-description projects. Their local evidence archives preserve source text, including original relative links. External research is retained as selective extracts with original URLs and precise locators; those files are not complete source archives. Browse the corresponding folders under ../skills for the complete maintained references. Current review notes and reader responses are retained; earlier drafts and private workspaces are outside this distribution.

The helper release checks validate current records and fingerprints, rather than reperforming recorded semantic or reader judgments. See ../docs/verification.md for commands.
